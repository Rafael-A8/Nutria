# M2.4.1b — Controlled Catalog Import UUIDv5 Golden Vector Correction

Data da correção: 29 de julho de 2026

Commit inspecionado: `37de9368f251be58318cb96fa353cca20b440b68`

## 1. Conclusão executiva corrigida

O defeito de comprimento presente nos vetores UUIDv5 de M2.4.1a foi confirmado de forma independente.

`leite condensado` possui exatamente 16 bytes em UTF-8. Os componentes canônicos que o representavam como `15:leite condensado` estavam incorretos e produziram uma cadeia UUIDv5 internamente reproduzível, porém incompatível com a regra congelada de prefixar cada componente pelo seu comprimento real em bytes.

Foram recalculados:

- o namespace raiz;
- os seis sub-namespaces fixos;
- todos os comprimentos dos componentes canônicos;
- o UUID da fonte;
- o UUID planejado da nova referência;
- o UUID da versão 1;
- o UUID da linhagem de alias;
- o UUID da revisão 1 do alias;
- o UUID de idempotência do lifecycle após a propagação do UUID corrigido da versão.

Todos os valores corrigidos fornecidos no pedido M2.4.1b coincidiram com os resultados independentes. Não foi encontrada nova incompatibilidade.

M2.4.1a permanece como registro histórico. Este relatório M2.4.1b substitui exclusivamente seus nomes canônicos e vetores UUIDv5 incorretos relacionados ao comprimento de `leite condensado`.

## 2. Explicação do defeito

O componente original foi congelado como:

```text
15:leite condensado
```

Contagem real dos bytes:

```text
leite       = 5 bytes
espaço      = 1 byte
condensado  = 10 bytes
total       = 16 bytes
```

O componente correto é:

```text
16:leite condensado
```

O texto contém somente caracteres ASCII, portanto sua contagem de caracteres também é 16. Ainda assim, o contrato não deve usar contagem de caracteres: deve medir sempre os bytes da codificação UTF-8 efetivamente recebida.

O erro propagava-se porque o UUID planejado da referência participa do nome canônico da versão e da linhagem de alias. A versão corrigida, por sua vez, participa do nome de idempotência do lifecycle.

A tentativa M2.4.2 tornou o defeito observável nos testes: 30 testes passaram e 3 falharam, com 122 assertions. A falha principal mostrou que o cálculo dinâmico produzia `16:leite condensado`, enquanto o vetor histórico exigia `15:leite condensado`. Os arquivos provisórios foram removidos e nenhuma implementação M2.4.2 permaneceu no repositório.

## 10. Requisito adicional congelado para M2.4.2

M2.4.2 deve implementar obrigatoriamente:

1. Comprimentos de componentes canônicos calculados dinamicamente sobre os bytes UTF-8 reais.
2. Nenhuma API produtiva deve receber do chamador um comprimento fornecido separadamente do texto.
3. Os testes não devem passar um comprimento independente para a API produtiva.
4. Deve existir ao menos um fixture não ASCII. O fixture mínimo congelado é:

   ```text
   café
   ```

   Resultado obrigatório:

   ```text
   caracteres Unicode: 4
   bytes UTF-8: 5
   componente canônico: 5:café
   ```

5. Cada golden-vector test deve afirmar simultaneamente:

   - o nome canônico completo;
   - o UUIDv5 resultante.

6. O fixture `leite condensado` deve afirmar:

   ```text
   v1|artifact|26:legacy_config_nutrition_v1|record_key|16:leite condensado
   ```

   e:

   ```text
   6e360841-51b8-5deb-a201-38debd0f03dc
   ```

## 11. Método de verificação independente

Dois cálculos independentes produziram os mesmos resultados:

1. `uuidgen --sha1`, usando os namespaces e nomes canônicos completos.
2. Uma implementação direta e descartável do RFC 4122 UUIDv5 em Perl:
   - namespace convertido de hexadecimal para 16 bytes;
   - nome codificado explicitamente em UTF-8;
   - SHA-1 binário de `namespace_bytes + name_bytes`;
   - primeiros 16 bytes do digest;
   - bits de versão definidos como `0101`;
   - bits de variante definidos como RFC 4122;
   - formatação canônica lowercase.

Os comprimentos foram calculados com `length(encode("UTF-8", $value))`.

O repositório possui `ramsey/uuid` em `composer.lock`, mas a verificação adicional via Composer/Sail não pôde executar porque o ambiente respondeu:

```text
Docker or Podman is not running.
```

Nenhum PHP do host foi usado, respeitando a exigência de executar PHP somente por Laravel Sail.

## 12. Precedência histórica e retomada

M2.4.1a continua íntegro como artefato histórico e não foi silenciosamente reescrito.

M2.4.1b substitui somente:

- `15:leite condensado` por `16:leite condensado`;
- o UUID planejado da referência dependente desse componente;
- o UUID da versão dependente da referência;
- o UUID da linhagem dependente da referência e do alias corrigido;
- o UUID da revisão dependente da linhagem;
- o UUID de idempotência dependente da versão corrigida.

Todas as demais decisões de M2.4.1 e M2.4.1a permanecem vigentes.

M2.4.2 pode ser reiniciado depois que esta correção for aceita. A nova implementação deve usar somente os vetores corrigidos deste relatório.
